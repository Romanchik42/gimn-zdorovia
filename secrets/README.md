# Локальные секреты

Файл `.env` в этой папке предназначен для локальных ключей и токенов подключения.

Не храните здесь обычные пароли от аккаунтов, если сервис поддерживает API-токены или секреты с ограниченными правами. Не добавляйте реальные значения в `.env.example`.

Пример переменных:

```env
VSCODE_TOKEN=
SUPABASE_URL=
SUPABASE_ANON_KEY=
SUPABASE_SERVICE_ROLE_KEY=
VERSAL_TOKEN=
TELEGRAM_BOT_TOKEN=
```

При работе с проектом я смогу прочитать этот файл по необходимости, но не просматриваю его самопроизвольно и не выполняю периодический мониторинг. Файл исключён из Git через корневой `.gitignore`.
