# Шрифты для PDF

PT Sans, обычное и полужирное начертание. Нужны генератору печатных версий
юридических документов (`src/lib/legal/pdf.ts`, GIMN-029).

**Почему шрифт лежит в репозитории.** У PDF нет «системных» шрифтов с
кириллицей: четырнадцать встроенных начертаний стандарта PDF содержат только
латиницу, и без вложенного файла весь русский текст вышел бы квадратами.
Поэтому шрифт вкладывается в документ, а значит должен быть под рукой на
сервере во время сборки PDF.

**Почему не `public/`.** Оттуда файлы раздаются браузеру через CDN и на диске
serverless-функции их может не быть. Папка `assets/` в раздачу не попадает, а
в функцию её кладёт `outputFileTracingIncludes` в `next.config.ts`.

**Почему PT Sans.** Сделан ParaType специально для языков России, полная
кириллица со всеми буквами, кавычками-ёлочками и знаком номера; лицензия
позволяет вкладывать его в документы без оговорок.

| Файл | Что это |
|---|---|
| `PTSans-Regular.ttf` | Основной текст |
| `PTSans-Bold.ttf` | Заголовки |
| `OFL.txt` | Лицензия SIL Open Font License 1.1 |

Источник: [Google Fonts](https://fonts.google.com/specimen/PT+Sans),

вместе со шрифтом — он в `OFL.txt`, удалять его нельзя.
