# Гимн.здоровья

Гимнастика для здоровья при болезни Бехтерева и для поддержания формы.
Персональная программа на день, меню, прогресс, напоминания в Telegram.

Прод: https://gimn-zdorovia.vercel.app · Бот: [@gimn_zdorovia_bot](https://t.me/gimn_zdorovia_bot)

---

## Запуск

```bash
pnpm install
pnpm dev
```

Переменные окружения — по образцу `.env.example`. Реальные значения лежат
в `secrets/.env` локально и в настройках проекта на Vercel.

## Проверки

```bash
npx tsc --noEmit        # типы
npx eslint              # стиль
npx next build          # сборка
npm run check:turnik    # режимы и снаряд: турник не протекает в Бехтерева
npm run check:points    # баллы: нет двойного начисления за одну ссылку
```

Тестового раннера в проекте нет. Проверки `check:*` — обычные скрипты на
штатном стриппинге типов Node; падают ненулевым кодом.

## База данных

Миграции — в `supabase/migrations/`, по одной на изменение, нумерация
сквозная. `supabase/apply_all.sql` собирается из них скриптом и не правится
руками:

```bash
node scripts/build-apply-all.mjs                                  # пересобрать apply_all.sql
node scripts/apply-migration.mjs supabase/migrations/00NN_....sql # применить одну миграцию
```

## Где что лежит

Подробная карта — в [PATHS_AND_BRANCHES.md](PATHS_AND_BRANCHES.md).
Грабли, на которые уже наступали, — в [MINES.md](MINES.md).
Чеклист ручной проверки перед выкладкой — в [CHECKLIST_TESTING.md](CHECKLIST_TESTING.md).
