# Чеклист проверки «Гимн.здоровья»

Прогонять целиком перед каждым выкладыванием на прод и после каждой миграции
базы. Один проход — телефон, один — компьютер: половина находок вылезает
только на узком экране.

**Как отмечать.** ✅ работает · ⚠️ работает, но криво · ❌ не работает.
Криво и не работает — сразу строчкой в «Найденное» внизу, с тем, что было на
экране, иначе через день никто не вспомнит.

**Чего этот чеклист не заменяет.** Всё ниже проверяется руками на живом
Supabase. Статическая проверка кода (`tsc`, `eslint`, `next build`) ловит
другое и обязательна до, а не вместо.

---

## 0. Перед прогоном

- [ ] Миграции применены: `supabase/apply_all.sql` прогнан в Supabase → SQL Editor.
- [ ] `node scripts/build-apply-all.mjs` не показывает разницы (файл собран из актуальных миграций).
- [ ] `npx tsc --noEmit` — чисто.
- [ ] `npx eslint` — чисто.
- [ ] `npx next build` — собирается.
- [ ] В Vercel заданы все переменные из `.env.example`.

## 1. Вход

- [ ] `/` открывается без входа, не падает в 500.
- [ ] Кнопка «Начать» ведёт на регистрацию.
- [ ] Вход через кнопку Telegram Login — пускает.
- [ ] Вход из бота (кнопка «Открыть») — пускает без повторного подтверждения.
- [ ] Команда `/start` боту — приходит ответ с кнопкой.
- [ ] Повторный вход не создаёт второй аккаунт (в `users` одна строка на telegram_id).
- [ ] Чужая/просроченная подпись Telegram — отказ, а не вход.

## 2. Онбординг

- [ ] Экран приветствия → выбор режима.
- [ ] Режим «Бехтерева»: все блоки диагностики проходятся, «не знаю» принимается.
- [ ] Углублённая диагностика: 6 блоков, любой вопрос можно пропустить.
- [ ] Выводы диагностики показываются человеку (какие положения заменим, какие зоны щадим).
- [ ] Режим «Общая форма»: пол, возраст, вес, рост, цель, активность, уровень, дни.
- [ ] **Вопрос «У вас есть турник?»** — три кнопки, ответ сохраняется.
- [ ] После анкеты общего режима показана норма калорий.
- [ ] Выбор темы, затем главный экран.
- [ ] Прерванный онбординг: вход заново возвращает туда же, а не в пустое приложение.

## 3. Главный экран

- [ ] Имя в приветствии.
- [ ] Карточка дня: фокус, длительность, состав.
- [ ] День отдыха показан как день отдыха, а не как пустая тренировка.
- [ ] Полоска регулярности за 7 дней, сегодняшний день обведён.
- [ ] «Мои тренировки» — сохранённые шаблоны, запуск с карточки.
- [ ] Переключалка режимов видна, только если активны оба.

## 4. Тренировка

- [ ] «Начать» собирает занятие; повторное нажатие не плодит вторую тренировку на день.
- [ ] Выбор длины (короткое / среднее / полное) до первой отметки.
- [ ] После первой отметки выбор длины пропадает.
- [ ] Картинка или схема есть **у каждого** упражнения, ни одного пустого квадрата.
- [ ] Стрелки на схемах показывают то же движение, что описано в технике.
- [ ] Кнопка ✅ «Сделал» — переход к следующему.
- [ ] Кнопка ⚠️ «Плохо» — открывается опрос симптомов.
- [ ] В опросе: совет, «Продолжить» и «Остановиться» работают обе.
- [ ] Кнопка ❌ «Пропустить» — переход без записи «сделал».
- [ ] «Назад» на первом упражнении уводит на главный, дальше — на шаг назад.
- [ ] Возврат назад и повторная отметка перезаписывает прежнюю, а не добавляет вторую.
- [ ] Финальный экран «Тренировка завершена», счётчик совпадает.
- [ ] После завершения тренировка отмечена `completed` (полоска регулярности закрасилась).
- [ ] Уход со страницы в момент перехода — звук следующего упражнения не догоняет.
- [ ] Выключить сеть, отметить упражнение → «нет сети», занятие продолжается.
- [ ] Включить сеть → «Связь вернулась — отправили отметки».

## 5. Турник (GIMN-014)

- [ ] Ответ «Да» → в занятии и в каталоге появляются висы/подтягивания.
- [ ] Ответ «Нет» → турниковых упражнений нет нигде: ни в дне, ни в каталоге, ни в конструкторе.
- [ ] Ответ «Могу найти» → турниковые приходят последними и с пометкой «нужен турник».
- [ ] Настройки → «Анкета общего режима» → прошлые ответы подставлены.
- [ ] Смена ответа с «Да» на «Нет» → сегодняшняя не начатая тренировка пересобралась без турника.
- [ ] Повторная анкета **не** сбросила правки недельного плана.
- [ ] В режиме «Бехтерева» турниковых упражнений нет ни при каком ответе.

## 6. Каталог и конструктор

- [ ] `/app/exercises` — поиск по названию.
- [ ] Фильтры «Зона», «Тип», «Длительность», счётчик «Найдено».
- [ ] У каждой строки значок движения.
- [ ] Раскрытие карточки: схема, описание, техника, предупреждение.
- [ ] Конструктор: фокус, длительность, интенсивность → черновик собирается.
- [ ] Противопоказанное добавляется только после подтверждения.
- [ ] «Начать сейчас» и «Сохранить как шаблон» — обе.
- [ ] Сохранённый шаблон виден на главном.

## 7. План

- [ ] `/app/plan` — семь дней, фокус, минуты, интенсивность, день отдыха.
- [ ] Предупреждения о плохом плане показываются и ничего не блокируют.
- [ ] «Сохранить» → «План сохранён».
- [ ] «Назад» с несохранёнными правками спрашивает.
- [ ] «Вернуть рекомендуемый» возвращает.
- [ ] Изменения видны на главном со следующего дня.

## 8. Питание

- [ ] Три вкладки: «Сегодня», «Покупки», «Неделя».
- [ ] Отметка «съедено» сохраняется после перезагрузки.
- [ ] Счётчик калорий за день считается с учётом размера порции.
- [ ] Размер порции меняется, калории пересчитываются.
- [ ] Список покупок собран из меню недели; отметки «куплено» сохраняются.
- [ ] «Собрать меню заново» спрашивает подтверждение и пересобирает.
- [ ] У пользователя Бехтерева анкета калорий открывается из «Питания» и **не** переключает режим.

## 9. Прогресс

- [ ] Вес, скованность, тест Шобера вводятся и сохраняются.
- [ ] График рисуется, при одном замере не ломается.
- [ ] История тренировок, отметки по упражнениям.
- [ ] Прогресс общий для обоих режимов, график регулярности — по режиму.

## 10. Профиль и настройки

- [ ] Имя, почта, телефон сохраняются; кривая почта не принимается.
- [ ] Выбор аватара из 12.
- [ ] Загрузка своего фото: обрезка по центру, превью, «Сохранить».
- [ ] Файл больше 5 МБ и не-картинка — понятный отказ.
- [ ] «Убрать фото» возвращает выбранный аватар.
- [ ] Длина занятия по умолчанию.
- [ ] Напоминания: включение, время утром и вечером с шагом 15 минут.
- [ ] Привязка Telegram, если вход был не через бота.
- [ ] «Показать тур заново» — тур запускается.

## 11. Оформление

- [ ] Все 7 палитр переключаются, цвет держится после перезагрузки.
- [ ] Авто-смена темы по времени суток.
- [ ] Конструктор своей палитры: фон, текст, карточка, свечение.
- [ ] Предупреждение о низком контрасте появляется.
- [ ] Тон инфо-табличек меняется.
- [ ] **Тёмная тема «Графит»: всплывающие сообщения тоже тёмные.**
- [ ] **Цвет строки браузера меняется вместе с темой.**
- [ ] Тема, выбранная на телефоне, приезжает на компьютер.

## 12. Звук

- [ ] Переключатель «Звуки при отметках».
- [ ] Все 6 наборов переключаются, «▶ Послушать» играет до сохранения.
- [ ] Громкость меняется и сохраняется.
- [ ] «Без звука» — тишина.
- [ ] В беззвучном режиме телефона приложение не шумит.

## 13. Режимы

- [ ] Подключение второго режима через его анкету.
- [ ] «Посмотреть» показывает режим, ничего не сохраняя.
- [ ] Переключение показывает данные того режима: план, тренировки, меню, история.
- [ ] Данные первого режима не потерялись.
- [ ] Режим активен только после своей анкеты.

## 14. Поделиться и рефералы

- [ ] Кнопка в шапке и в настройках открывает модалку.
- [ ] QR виден, читается камерой телефона.
- [ ] QR читается с распечатки.
- [ ] «Сохранить картинку» скачивает PNG.
- [ ] «Отправить»: системное меню / выбор чата Telegram / копирование.
- [ ] «Копировать ссылку».
- [ ] Счётчик «по вашей ссылке пришло».
- [ ] Переход по `/i/КОД` показывает «Вас пригласил(а) …».
- [ ] Регистрация по ссылке привязывает пригласившего.
- [ ] Несуществующий код не ломает страницу.

## 15. Отзывы

- [ ] Отзыв / ошибка / идея отправляются.
- [ ] Текст короче 3 и длиннее 2000 символов — отказ.
- [ ] Запись появилась в таблице `feedback`.
- [ ] Уведомление пришло админу в Telegram.

## 16. Бот и напоминания

- [ ] Утреннее напоминание приходит в заданное время.
- [ ] Вечернее приходит, если занятия не было.
- [ ] Кнопка из бота открывает приложение.
- [ ] Сообщения о тренировке удаляются при переходе в приложение, «домашнее» остаётся.
- [ ] Персональный отчёт приходит в срок.

## 17. Мобильное и PWA

- [ ] Всё меню помещается в 360 пикселей ширины, ничего не вылезает.
- [ ] Кнопки не меньше 44 пикселей.
- [ ] Нижняя навигация не перекрывается системной полосой (safe-area).
- [ ] «Добавить на главный экран» на Android — открывается без адресной строки.
- [ ] «На экран "Домой"» на iPhone — ярлык с иконкой.
- [ ] Без сети открывается последняя тренировка, иначе — страница «нет сети».
- [ ] Сброс аккаунта чистит кеш страниц: чужих данных на устройстве не остаётся.

## 18. Админ

- [ ] `/admin/stats` открывается только админом, остальным — отказ.
- [ ] Цифры сходятся.
- [ ] «Сбросить мой аккаунт» стирает только свои данные и закрывает сессию.
