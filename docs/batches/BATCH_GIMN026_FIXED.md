## ФИК #1: СТРАНИЦА ВХОДА — Один чёрный прямоугольник

### Симптом
Страница: `https://gimn-zdorovia.vercel.app/auth/login`

На скрине видно:
```
🧘 [иконка]
Гимн.здоровья
Войдите через Telegram, чтобы продолжить занятия

[ЧЁРНЫЙ ПРЯМОУГОЛЬНИК]  ← здесь должна быть кнопка "Войти через Telegram"

Кнопка не появилась? Откройте бота в Telegram
```

**НА ЭТОЙ СТРАНИЦЕ QR КОДА НЕТ И БЫТЬ НЕ ДОЛЖНО.** Только одна кнопка входа.

### Причина
Компонент `TelegramLoginButton` (или `TelegramAuth`) не рендерится — вероятно:
- Не подгружен скрипт `telegram-widget.js`
- Или ошибка импорта компонента
- Или условный рендеринг сломан

### Решение

**Шаг 1: Найти компонент**

Проверить по порядку:
- `src/app/auth/login/page.tsx`
- `src/components/auth/TelegramLoginButton.tsx`
- `src/components/auth/LoginForm.tsx`

**Шаг 2: Что должно быть**

Стандартная кнопка Telegram Login (белая по умолчанию, потом меняется темой):

```tsx
<a
  href={`https://t.me/gimn_zdorovia_bot?start=login`}
  className="inline-flex items-center gap-2 bg-white text-black px-6 py-3 rounded-lg font-medium shadow hover:shadow-lg transition"
>
  <TelegramIcon /> Войти через Telegram
</a>
```

Референс цвета: визитка (белая кнопка "ai-arhitektor.ru").

**Шаг 3: Если используется официальный виджет Telegram**

```tsx
<script async src="https://telegram.org/js/telegram-widget.js?22" 
        data-telegram-login="gimn_zdorovia_bot"
        data-size="large"
        data-onauth="onTelegramAuth(user)"
        data-request-access="write"></script>
```

Проверить, что скрипт загружается (посмотреть Network в DevTools).

**Шаг 4: Проверить в браузере**
- Открыть `/auth/login`
- Кнопка должна быть **видна**, а не чёрный прямоугольник
- Клик → перенаправляет в Telegram-бот

## ФИК #2: QR КОД на странице "Поделиться"

### Симптом
Страница: `/share` (или в настройках → "Поделиться приложением")

QR код почти невидим (светло-серый на светлом фоне).

### Референс
Визитка (скрин из Telegram): QR **чёрный на белом**, читается отлично.

### Решение

**Шаг 1: Найти компонент**

- `src/components/Share.tsx`
- `src/app/(app)/share/page.tsx`

**Шаг 2: Настроить цвета QR**

Было (вероятно):
```jsx
<QRCode value={link} bgColor="..." fgColor="..." />
```

Стало:
```jsx
<div className="bg-white p-6 rounded-lg inline-block">
  <QRCode 
    value={link}
    bgColor="#FFFFFF"
    fgColor="#000000"
    size={250}
    level="H"
    includeMargin={true}
  />
</div>
```

**ВАЖНО:** QR всегда белый на чёрном (по умолчанию), независимо от темы приложения. Тема меняет остальной интерфейс, но не QR — иначе камерам сложно сканировать.

**Шаг 3: Проверить**
- Открыть `/share`
- Сканировать QR телефоном → должен открыться Telegram-бот

## НОВОЕ #4: ПРИВЕТСТВЕННОЕ СООБЩЕНИЕ БОТА

### Проблема

Когда человек первый раз открывает `@gimn_zdorovia_bot` (по кнопке или приглашению), бот шлёт **сухое** сообщение:
```
Приветствую. Нажмите на кнопку для регистрации.
[Открыть приложение]
```

**Роман хочет:** тёплое, доброе, с описанием возможностей приложения.

### Решение

**Шаг 1: Найти обработчик /start**

Ищи в:
- `src/bot/handlers/start.ts`
- `src/api/telegram/webhook.ts`
- `src/lib/telegram/handlers.ts`
- Файл содержит: `bot.command('start', ...)` или `case 'start':` или `text === '/start'`

**Шаг 2: Новое сообщение**

Заменить текст на:

```
👋 Приветствую, {имя}!

Рад видеть вас в «Гимн.здоровья» — вашем персональном тренере для реабилитации при болезни Бехтерева и общей физической формы.

Что вас ждёт:

🧘 Упражнения ЛФК с понятной техникой
📊 Персональная программа на каждый день
🥗 Меню и подсчёт калорий
💪 Прогресс и статистика
⏰ Напоминания в удобное время

Программа подстраивается под ваше самочувствие — обычно 30 минут в день.

⚠️ Важно: «Гимн.здоровья» — вспомогательный инструмент. Перед началом занятий проконсультируйтесь с врачом-ревматологом.

Готовы начать? Нажмите кнопку ниже 👇

[🚀 Открыть приложение]
[💬 Написать в поддержку]
```

**Шаг 3: Клавиатура**

```ts
const keyboard = {
  inline_keyboard: [
    [{ text: '🚀 Открыть приложение', web_app: { url: 'https://gimn-zdorovia.vercel.app' } }],
    [{ text: '💬 Написать в поддержку', url: 'https://t.me/YOUR_SUPPORT_USERNAME' }]
  ]
};
```

**Шаг 4: Подставить имя из Telegram**

```ts
const name = ctx.from.first_name || 'друг';
const message = welcomeText.replace('{имя}', name);
```

**Шаг 5: Аудит других сообщений бота**

Заодно посмотреть, есть ли другие сухие сообщения:
- Сообщение при повторном /start (для уже зарегистрированных)
- Сообщение при `/help`
- Сообщение при ошибке
- Утреннее и вечернее напоминание (уже есть, проверить тон)

**Все сообщения должны быть:**
- Дружелюбными, но не приторными
- Короткими (2–5 строк, если это не первое сообщение)
- С эмодзи в меру (1–2 на сообщение)
- На "вы" (медицинский контекст, уважительно)
