## 🩺 ФРОНТ 3: МЕДИЦИНА И НАУКА ТРЕНИРОВОК

### Официальные рекомендации (ACSM 2026)

**Новичок:**
- 2-3 тренировки в неделю
- 3 подхода × 8-12 повторов
- Отдых 60-90 сек между подходами
- Fullbody программа (не сплит)
- Веса **не увеличивать больше чем на 10%** в неделю
- Начинать с формы, не с веса
- Начальный вес = 60-70% от максимума (RM)

**Средний уровень:**
- 3-4 тренировки в неделю
- Возможен сплит (верх/низ или push/pull/legs)
- 3-5 подходов × 6-12 повторов
- Отдых 90-180 сек
- Периодизация (объём/интенсивность)

**Продвинутый:**
- 4-6 тренировок в неделю
- Полный сплит (грудь/спина/ноги/плечи/руки)
- 4-6 подходов × 4-12 повторов (варьируется)
- Отдых 2-5 мин на силовых
- Прогрессия нелинейная, деловые схемы

### Границы автопрогрессии (безопасность)

- **Максимум +10%/неделя** — иначе травмы
- **Проверка**: 3 успешные тренировки на текущем весе = +2.5кг (уровень новичок)
- **Стоп**: 2 неудачных подхода подряд = снизить вес на 10%
- **Дилоад**: раз в 4 недели — снижение объёма на 40%

### БЖУ для зала

Из прошлого аудита + подтверждено:
- **Белок**: 1.6-2.2 г/кг веса тела
- **Жир**: 0.8-1.0 г/кг веса тела (пол)
- **Углеводы**: остальное до калоража

**Пример** (80 кг, TDEE 2600):
| Цель | Ккал | Б, г | Ж, г | У, г |
|------|------|------|------|------|
| Похудеть (×0.8) | 2080 | 176 | 64 | 200 |
| Держать | 2600 | 144 | 80 | 326 |
| Набрать (×1.15) | 2990 | 160 | 83 | 401 |

**Сравнение с текущим меню (31/30/36% универсально):**
На массе: сейчас 229 Б / 100 Ж / 272 У vs надо 160 Б / 83 Ж / 401 У
- **+69 г белка** (избыточно, дорого)
- **-129 г углеводов** (мало для силовой работы!)

Значит: **вторая ось в подборе меню обязательна**.

### Замеры для автопрогрессии

**Минимум для алгоритма:**
- Вес тела (еженедельно)
- Обхваты: грудь, талия, бёдра (раз в 2 недели)
- % жира (можно через биоимпеданс дома или онлайн-калькулятор по обхватам)

**Расширенно:**
- Обхваты бицепса, бедра, голени
- Замеры силы (макс. отжимания, макс. подтягивания за 1 подход)
- Пульс покоя утром

### 3. Новая таблица дозировки

**Проблема:** сейчас есть только `duration_sec + repetitions + rest_sec` — этого мало для зала.

**Решение — новая таблица `exercise_dosage`:**

```sql
CREATE TABLE exercise_dosage (
  id UUID PRIMARY KEY DEFAULT gen_random_uuid(),
  exercise_id UUID NOT NULL REFERENCES exercises(id),
  level TEXT NOT NULL CHECK (level IN ('beginner', 'intermediate', 'advanced')),
  mode TEXT NOT NULL CHECK (mode IN ('behtereva', 'general', 'gym')),
  
  -- Гимнастика (Бехтерева, домашний фитнес)
  duration_sec INTEGER,
  repetitions INTEGER,
  rest_sec INTEGER,
  
  -- Силовые (зал)
  sets INTEGER,           -- количество подходов
  reps_per_set INTEGER,   -- повторов в подходе
  rest_between_sets_sec INTEGER,  -- отдых МЕЖДУ подходами (30-180 сек)
  weight_pct_1rm REAL,    -- % от 1RM или NULL если пустая штанга
  weight_kg_default REAL, -- рекомендуемый стартовый вес (или пустая штанга)
  
  notes TEXT
);
```

### 8. Оценка времени тренировки для зала

**Проблема:** сейчас `duration.ts` считает 4 сек/повтор + 15 сек отдых. Для зала это ~6× меньше реального.

**Решение:**

```typescript
// Гимнастика (текущая логика — оставить):
timeForGymnastics(exercise) = reps × 4 + rest_sec

// Силовые (новая логика):
timeForStrength(exercise, dosage) = 
  dosage.sets × (
    dosage.reps_per_set × 3 +          // 3 сек/повтор (медленней гимнастики)
    dosage.rest_between_sets_sec       // отдых МЕЖДУ подходами
  )

// Пример: приседания 3×8 с отдыхом 90 сек
// = 3 × (8 × 3 + 90) = 3 × 114 = 342 сек ≈ 5.7 мин
// vs текущий движок: 8 × 4 + 15 = 47 сек ≈ 0.8 мин
```

### 9. Меню (БЖУ) для зала

