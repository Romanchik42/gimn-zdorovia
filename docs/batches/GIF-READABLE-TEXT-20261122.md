# Крупные подписи к упражнениям

Роман: «Текст слишком мелкий. Нужно уместить его как то в шаблон. Даже в очках мелко».

Вынести необходимые подписи крупно в шаблон приложения, сохранить увеличенные вставки. Без платных генераций. Тексты взяты из сохранённых фаз и исходной техники, для обеих сторон отдельно. Шрифт фаз22px, полная техника20px, название26px. ГотовыеGIF не перегенерируются.
