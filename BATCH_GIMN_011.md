6 БЛОКОВ ВОПРОСОВ (все варианты ответа сохранять в user_diagnostics,
новые поля через миграцию):

Блок 1. Положения тела:
- Можете лежать на животе? (да / нет — больно или живот вздут)
- Можете лежать на спине с вытянутыми ногами? (да / с трудом / нет)
- Можете стоять без опоры? (да / нужна опора)
- Можете сидеть на полу? (да / с трудом / нет)

Блок 2. Руки и плечи:
- Обе руки поднимаются одинаково? (да / левая хуже / правая хуже)
- Насколько поднимается худшая рука? (до плеча / до груди / почти не поднимается)
- Можете завести руки за спину? (да / частично / нет)

Блок 3. Шея:
- Голова поворачивается в стороны? (свободно / немного / почти не крутится)
- Можете наклонить голову к плечу? (да / немного / нет)
- Можете посмотреть вверх/вниз? (да / немного / нет)

Блок 4. Позвоночник:
- Наклон вперёд: (свободно / немного / почти нет)
- Наклоны вбок: (свободно / немного / еле заметно)
- Повороты корпуса: (свободно / немного / почти нет)
- Прогиб назад: (да / немного / нет)

Блок 5. Ноги и таз:
- Лёжа на спине поднимаете ногу? (обе легко / по одной / ни одной)
- Можете расставить ноги на ширину плеч? (да / с трудом / нет)
- Отвести ногу в сторону? (да / немного / нет)
- Приседания/полуприсед? (да / держась за опору / нет)

Блок 6. Общее состояние:
- Растяжка есть? (нормальная / слабая / почти нет)
- Утренняя скованность: (до 30 мин / 30-60 мин / больше часа)
- Дни, когда движения совсем тяжело? (часто / иногда / редко)
- Давление скачет при нагрузке? (да / нет / не знаю)

ЛОГИКА ПОДБОРА (в движок workout-engine):
- Ответ «нет / почти нет» на ПОЗУ (живот, спина на полу, сидеть на полу)
  → упражнения из этого положения ИСКЛЮЧАЮТСЯ или заменяются аналогом
  из доступного положения (напр. лёжа→сидя/стоя).
- Ответ «нет / почти нет» на ЗОНУ (шея, наклоны, ноги, повороты)
  → зона НЕ исключается, а получает САМЫЕ ЩАДЯЩИЕ упражнения на развитие
  (микроамплитуда, изометрика — напряжение без движения). Это КЛЮЧЕВОЕ
  отличие: ограничение зоны = повод её мягко развивать, а не убирать.
- Асимметрия руки → нагрузка на слабую руку снижается, но НЕ убирается.
- «Растяжки почти нет» → старт с минимальной амплитуды, наращивание очень
  медленное.
- Шея особо: если «почти не крутится» → добавить мягкие упражнения на
  подвижность и мышцы вокруг шеи (микроповороты, наклоны малой амплитуды,
  изометрика). Контент — из существующих упражнений type=neck; если в
  справочнике мало шейных — добавь недостающие в seed по ASAS/EULAR
  (щадящие, с противопоказаниями), но БЕЗ переписывания существующих текстов.

Пересчёт calculated_intensity/focus с учётом углублённых ответов.
Углублённую диагностику можно пройти повторно из настроек.
